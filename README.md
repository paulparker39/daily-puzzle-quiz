# Daily School Quiz

A daily 5-question puzzle: one question each from **Math, Geography, History, Science, and Language Arts** — school-taught trivia adults tend to forget, styled like "Are You Smarter Than a 5th Grader" but slightly harder.

Fully static (HTML/CSS/JS, no backend) and deployable via GitHub Pages.

## How it works

- `questions/*.json` — a bank of 200+ free-response questions per subject.
- Each day, one question per subject is picked deterministically from a hash of the date, so every visitor sees the same daily puzzle.
- Answers are free-response and scored entirely client-side in `scoring.js`.
- Streaks are tracked in `localStorage`.
- After submitting, a compact shareable text summary is generated for copy/paste (e.g. into SMS).

## Scoring rules

All answers are free-response and always incur a **typo penalty**: `min(20, 5 × Levenshtein distance)` against the closest matching correct string, subtracted from a subject-specific base score.

- **Math** — numeric: `max(0, 100 - |user - correct| × 20)`. Symbolic: 100 if equivalent after normalization, else 0.
- **Geography** — population questions: `max(0, 100 - (|user - correct| / correct) × 200)`. Capitals/borders: exact/alias match = 100, otherwise lenient concept scoring. Physical geography: lenient concept scoring.
- **History** — year questions: `max(0, 100 - |user - correct| × 5)`. Names/events: exact/alias match = 100, otherwise lenient concept scoring. Broader questions: lenient concept scoring.
- **Science** — numeric: `max(0, 100 - |user - correct| × 10)`. Categorical (true/false, etc.): exact match = 100 else 0. Conceptual: lenient concept scoring.
- **Language Arts** — synonym similarity ≥ 0.80 → 80; same part-of-speech category → 60; same literary-device family → 60; otherwise 0.

**Lenient concept scoring** buckets a lexical-similarity score (character closeness + word-token overlap — a static-site-friendly proxy for semantic similarity, since there's no embeddings API in a pure client-side app): ≥0.85 → 80, ≥0.75 → 60, ≥0.65 → 40, else 0.

`final_score = max(0, base_score - typo_penalty)` for every question. Total is out of 500.

## Regenerating the math question bank

```
node scripts/generate_math.js
```

This deterministically (seeded) generates 200+ arithmetic, fraction, percentage, geometry, algebra, exponent, and symbolic-simplification questions into `questions/math.json`.

## Running locally

Any static file server works, e.g.:

```
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Deployed via GitHub Pages from the `main` branch root.
